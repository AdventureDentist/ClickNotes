Settings

Your details

The clinician and dental assistant names are used across every template. They’re saved in this browser on this computer only, so each person sharing the file can set their own.

Making it remember your details

Your details are saved by your web browser, not inside the file. Set them once on each computer and they’ll be there every time you open the page.

Best set-up

  • Use Chrome or Edge, and always open the page in the same browser on that computer.
  • Save the file somewhere permanent, such as your Desktop or Documents, rather than opening it from Downloads each time.
  • When you get a newer version, save it over the old one. Your details carry over.

Keep it one click away

  • Bookmark it: open the page and press Ctrl + D (⌘ + D on a Mac).
  • Pin the tab: right-click the page’s tab and choose Pin. It stays open at the left of your tabs.
  • Open it when the browser starts: in Chrome go to Settings, then On start-up, then Open a specific page or set of pages, and add this page. In Edge it’s Settings, then Start, home and new tabs. Copy the page address from the address bar; it starts with file:///.
  • Desktop shortcut (Windows): right-click the file, choose Show more options, then Send to, then Desktop (create shortcut).

Things that make it forget

  • Private, Incognito or InPrivate windows.
  • Clearing browsing data with Cookies and other site data ticked.
  • Opening the page in a different browser, browser profile or computer.

Defaults in each note

  • Your clinician name fills the Clinician line, and the first dental assistant listed is selected by default.
  • Common choices start selected, such as Articaine 4% 1:100,000, 1.8ml cartridges, C/O Nil and MH no changes. Tap a different option to change it for that note.
  • Double-click any option or sentence to reword it for the current note.
  • Nothing about patients is ever saved. Closing the page or pressing New note clears the note.

About this tool

Treatment Notes is a free, tap-through note builder for dental appointments: restorations, extractions, indirect preps and fits, endo and dentures. Tap the options that match what you did and it writes a clear, consistently structured clinical note, ready to paste into your practice management software.

Why use it

  • Free. No subscription, login or per-clinician licence.
  • Fast and consistent. Every note follows the same structure, with risks, consent and post-op advice as tick boxes so nothing gets missed.
  • Private by design. It runs entirely in your browser from a single file. Nothing about patients is saved or sent anywhere, and closing the page clears the note.
  • Works offline. No internet connection, server or account needed, so it keeps working if the network drops.
  • Fully editable. It’s one plain HTML file, so you can change any option, sentence or default to suit how you work, with help from an AI assistant such as Claude.

Changing the options with Claude

  1. Go to claude.ai and start a new chat.
  2. Attach your Treatment Notes HTML file.
  3. Describe the change in plain words, for example: “In the Extraction tab, add Coronectomy to the method options, and make Lidocaine 2% the default anaesthetic in every tab.”
  4. Ask Claude to make the change in the file and give you back the complete updated file to download. The option lists sit near the top of each tab’s script, which makes them easy to find.
  5. Save the new file over your old one and open it to check. Your details carry over.

Keep a copy of the old file until you’ve checked the new one, and make one or two changes at a time.
